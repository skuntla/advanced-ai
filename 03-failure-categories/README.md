# Fourteen enterprise AI failure categories

A failure atlas is not a list of symptoms only. For each failure, learn **how to detect it, contain it, prove its root cause, remediate, demonstrate prevention and account for the residual risk**.

- **F01** [Business failure](01-business-failure/README.md) — Solution does not solve the right problem or create measurable value.
- **F02** [Data failure](02-data-failure/README.md) — Missing, corrupt, duplicated, inconsistent or out-of-order data.
- **F03** [Knowledge failure](03-knowledge-failure/README.md) — Missing or stale retrieved evidence, wrong document version, citation gaps.
- **F04** [Model failure](04-model-failure/README.md) — Incorrect prediction, hallucination, drift, miscalibration or unexpected behavior.
- **F05** [Security failure](05-security-failure/README.md) — Broken authentication/authorization, cross-tenant access and leakage.
- **F06** [Adversarial failure](06-adversarial-failure/README.md) — Prompt injection, malicious tool responses and poisoned content.
- **F07** [Integration failure](07-integration-failure/README.md) — Dependency API fails, violates contract or produces unknown status.
- **F08** [Transaction failure](08-transaction-failure/README.md) — Duplicate, partial, unreconciled or in-doubt business transaction.
- **F09** [Agent failure](09-agent-failure/README.md) — Wrong tools, runaway loops, bad plan, loss of state or excessive autonomy.
- **F10** [Concurrency failure](10-concurrency-failure/README.md) — Races, lost updates, version conflicts and duplicate parallel work.
- **F11** [Performance failure](11-performance-failure/README.md) — Latency, resource exhaustion and throughput shortfall.
- **F12** [Infrastructure failure](12-infrastructure-failure/README.md) — Cloud, model provider, network, region or hardware becomes unavailable.
- **F13** [Operational failure](13-operational-failure/README.md) — Bad deployment, missing monitoring, version mismatch or poor rollback.
- **F14** [Governance failure](14-governance-failure/README.md) — Unapproved model use, insufficient audit, accountability or policy breach.
