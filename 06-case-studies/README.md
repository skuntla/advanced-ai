## Interview rule
1. Answer the executive in 90 seconds: business decision, highest risk, plan, success measures.
2. Expand architecture and trade-offs only when challenged.
3. On changed constraints, revise assumptions and defend decisions.
4. Use no coding agent during cold interview; use one afterward for a falsifying experiment.
